# dicom-synth

Toolkit for creating synthetic test data for medical imaging software.

## ⚠️ Disclaimer

This project is currently in a pre-1.0.0 state. APIs and behavior may change at any time without notice.

You're welcome to open issues, but please only do so if you're also willing to contribute a pull request.

## Why

This provides an open and ready-to-use library for creating highly variable, synthetic DICOM _files_, for the purpose of aiding validating and stress testing medical imaging software.

The library is intended to be toolkit-agnostic and deterministic, allowing in-memory file generation for testing pipelines, and/or file output for larger, persistant collections.
